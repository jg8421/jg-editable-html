最小样例：一个可以被任意编辑的 HTML

这个文件本身就是用 build_panel.py 生成的。打开后：点任意元素 → 工具条；鼠标划过文字 → 右侧 A− / A+；Ctrl+S → 保存回本文件。

结论（黄色框，随便改）
  • 点这一行 → 出现工具条 → 直接改字、改字号、改颜色、删除。
  • 鼠标移到这一行上 → 右侧出现 A− 15.5px A+，点一下就能调大小。
  • 点选之后按钮会钉住，鼠标挪过去也不会消失。

3. 手写 SVG 图表（连图里的数字都能改）

4. 加批注

把右下角「✎ 任意编辑」关掉 → 选中任意一句话 → 点浮出的「＋ 批注」→ Ctrl+Enter。右缘的「批注」标签里能看到全部批注，可以定位、标已处理、导出 .md。
