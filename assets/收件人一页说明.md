# 这个 HTML 怎么改、怎么批注（收件人一页说明）

> 单文件 HTML，双击打开。**批注和修改都存在文件里**，发给谁就跟到谁。

---

## 0. 先认识右上角那个开关：阅读 ｜ 编辑

打开时默认是 **阅读模式** —— 页面最干净：鼠标划过不会有橙色虚框，顶部导航、分页按钮、折叠面板都能正常点。

要改东西，点右上角的 **「编辑」**（变绿 = 编辑中）；改完点回 **「阅读」** 即可。无论哪种模式，右下角的 **💾 保存** 一直在屏幕里。

---

## 1. 任意元素编辑（先把右上角切到「编辑」）

打开就能改 —— 页面右下角显示 **「✎ 任意编辑：开」**。

**点任意元素**（正文、表格单元格、表头、卡片、**图表里的数字**、整段、整个章节都行）→ 浮出工具条：

| 工具条上的控件 | 作用 |
|---|---|
| **字号** | 下拉选 12–56px（图表里的数字是 8–28px）；**也可以直接用鼠标划过文字时右侧浮出的 `A− 15.5px A+` 微调**（见下） |
| **字体** | Arial / 楷体 / 宋体 / 雅黑 / 跟随正文 |
| **宽 / 高 / 内距 / 外距** | 填数字＝像素；也可填 `auto`、`60%` |
| **色块（两排）** | 第一排＝文字颜色，第二排＝底色；最左的白块＝清除 |
| **A** | 改文字（等于双击） |
| **`</>`** | 直接改这段的 HTML（标签、class、style 都能改） |
| **⬆ ⬇** | 上移 / 下移（同级调顺序） |
| **⧉** | 复制一份 |
| **↺** | 撤销上一步（键盘 **Ctrl+Z** 也行） |
| **× 删除** | 删掉这个元素；**选中后直接按 `Delete` 或 `Backspace`（退格）也一样** |

> **删除会自动补位**：从一排卡片里删掉一个，剩下的**自动铺满整行**（不留空档）；表格删一行/一列、列表删一条，后面的自动上移。删错了按 **Ctrl+Z** 就回来。

**图表（SVG）也能改**：点图表里的某一个数字，工具条会变成图表专用版 —— **字号 / 文字内容 / 颜色 / ← → ↑ ↓ 微调 / 删除**。比如把重叠的数字挪开、改个颜色、删掉不要的标签。

**双击任意文字** = 直接改字（绿色框内输入，点空白处生效，Esc 取消）。

**键盘快捷键**：`Delete` / `Backspace` = 删掉当前选中的元素；`Ctrl+Z` = 撤销；`Esc` = 取消选中。

### 1.1 鼠标划过 → 右边浮出 `A− 15.5px A+`（最快调字号的方式）

**鼠标移到任意一段文字上**（段落、列表项、表格单元格、卡片里的字、**图表里的数字**……），该段文字右侧就会浮出一个小控件：

```
A−   15.5px   A+
```

- **A+** ＝ 放大一档，**A−** ＝ 缩小一档（档位：12 → 13 → 14 → 15 → 16 → 18 → 20 → 22 → 24 → 28 → 32 …）
- 中间显示**当前字号**，点一下立刻生效
- 只会改**你划过的那一块**，不影响别的文字
- 整行很宽的文字，控件会**贴在屏幕最右侧**，不会被挤出视野

> **推荐用法：先点一下那段文字（选中），按钮就会"钉"住** —— 这时你把鼠标慢慢挪到 `A+` 上也不会消失，可以连续点好几下。
>
> 不点选、纯粹用鼠标划过去也能用（划到哪段就调哪段），只是鼠标一移开它会跟着换位置。

> 例：鼠标移到某个 `<li>` 上 → 出现 `A− 15.5px A+` → 点两下 `A+` → 这一条变成 17px，其它条目不变。

### 想让链接恢复可点 / 安静阅读

- 导航标签、右下角翻页、术语表折叠 —— **一直是正常可点的**（不会被编辑模式接管）。
- 想编辑这些元素：**按住 Alt 再点**。
- 只想安静阅读：点右下角把 **「任意编辑：关」**。想再开回来点一下即可。
- 想加**文字批注**：先关掉「任意编辑」，再选中文字 → 点浮出的「＋ 批注」。

## 2. 加批注

1. 关掉右下角「任意编辑」；
2. 选中文字 → 点浮出的 **「＋ 批注」** → 写 → **Ctrl+Enter**；
3. 点右缘蓝色竖标签 **「批注」**（或 Alt+N）看全部；每条可**定位 / 标已处理 / 删除**。

---

## 3. 保存：Ctrl+S 或点右下角「💾 保存」

### 第一次：选一次文件夹

打开后**第一次**按 Ctrl+S → 弹出文件夹选择框 → **选中这个 HTML 所在的文件夹** → 完成。

- 选完**立刻覆盖保存**当前文件
- 从此 **Ctrl+S 直接覆盖，不再弹任何窗口**
- 而且**这个文件夹里以后所有版本的 HTML 都免弹窗**（包括你新做 v2、v3）
- 保存按钮会从 `💾 保存` 变成 **`💾 保存 ✓`**，表示已经记住授权

### 为什么第一次这个框不在当前文件夹？

**浏览器不允许网页知道"我这个文件在哪个文件夹"** —— Chrome 没有"从文件反查目录"的接口，
也没有"路径 → 目录句柄"的 API。所以第一次弹窗开在哪，只能由浏览器决定（默认是"下载"）。
这是浏览器的安全模型，**任何网页方案都绕不过去**；能做的就是把次数压到**一辈子一次**。

> 好消息：Chrome 会记住你上次在这个网站用过的目录。**你选过一次之后，以后连其它文件的选择框都会默认开在那个文件夹。**

### 备选：把文件直接拖进页面（同样零弹窗）

从资源管理器把**当前这个 HTML 文件**拖到页面中央 → 松手即可授权。只对这一个文件有效。

## 4. 发给别人 / 收别人的意见

- 直接把文件发出去，对方打开就能看到你的批注和修改，也能继续改。
- 对方发回后：打开**你的副本** → 抽屉里点「导入」→ 选对方文件 → 按 id 合并、按时间取新。

## 5. 其他

- 顶部标签点一下就跳到对应章节，滚动时自动高亮。
- 右下角胶囊：上一节 / 第几节 / 下一节 / 回到顶部。
- **Ctrl + P** 打印或存 PDF（图是矢量，放大不糊）。打印时编辑工具条会自动隐藏。
- 全部改动想推倒重来：浏览器控制台执行 `PVAnyEdit.clear()`。
- 打开的是旧版本时，按 **Ctrl + F5** 强制刷新。
